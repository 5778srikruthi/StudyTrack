# StudyTrack — Development Log

## Project Overview

StudyTrack is a student study and task management system designed to help students organize their study tasks and track their progress.

## Milestone 1: Project Setup

- Created the project folder structure.
- Organized frontend, backend, database, and documentation folders.
- Initialized Git and created the initial project commits.
- Created a GitHub repository for version control.

## Milestone 2: Frontend Foundation

- Created the home page.
- Created login and registration pages.
- Added shared CSS styling.
- Connected frontend pages using HTML links.

## Milestone 3: Backend and Database

- Set up a Java Spring Boot backend.
- Connected the backend to MySQL.
- Created the User model, repository, service, and authentication controller.
- Implemented user registration and login.
- Added BCrypt password hashing.

## Milestone 4: Dashboard and Task Management

- Created the StudyTrack dashboard.
- Added a task input and Add Task button.
- Implemented dynamic task creation using JavaScript.
- Added checkboxes to mark tasks as completed.
- Implemented total, completed, and pending task counters.
- Updated completed and pending counts when a checkbox is changed.

## Current Status

- Users can register and log in.
- The dashboard displays tasks added during the current page session.
- Tasks can be marked as completed.
- Task counters update dynamically.

## Next Milestones

- Persist tasks so they remain after page refresh.
- Store tasks in MySQL through Spring Boot.
- Associate tasks with individual users.
- Build completed-task history with completion dates.
- Add study statistics and progress tracking.

## Learning Notes

- Practiced HTML structure and form elements.
- Learned CSS file linking.
- Practiced JavaScript DOM manipulation.
- Learned event listeners for buttons and checkboxes.
- Practiced sending HTTP requests from JavaScript to a Spring Boot backend.
- Learned the role of MySQL, Git, and GitHub in application development.
